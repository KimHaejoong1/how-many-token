# How Many Token

ChatGPT 설정의 **주간 사용 한도**를 확장프로그램 아이콘 한 번으로 확인하는 Chrome 확장프로그램입니다.

- 가로 400px, 간결한 팝업
- 브라우저가 전달하는 라이트/다크 설정을 자동으로 반영
- 주간 잔여량, 초기화까지 남은 시간
- 잔여량에 따라 연두(100%) → 노랑(50%) → 빨강(0%)으로 바뀌는 막대
- 팝업을 열 때 조회, 열려 있는 동안 1분마다 갱신, 수동 새로고침
- ChatGPT 탭이 없으면 브라우저의 로그인 세션으로 직접 조회하는 실험 기능

## 설치

별도 빌드나 npm 설치가 필요 없습니다.

이 저장소의 **Code → Download ZIP**으로 소스를 받은 뒤 압축을 풀거나, 저장소를 클론해 주세요.

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. `manifest.json`이 들어 있는 이 폴더를 선택합니다. ZIP을 받았다면 먼저 압축을 풀어 주세요.
5. 같은 Chrome 프로필에서 ChatGPT에 한 번 로그인합니다. 이미 열려 있던 **ChatGPT 탭은 한 번 새로고침**합니다. 로그인 후에는 탭을 닫고 조회할 수 있습니다.
6. Chrome의 퍼즐 아이콘에서 **How Many Token**을 고정한 뒤 아이콘을 누릅니다.

## 사용

같은 Chrome 프로필의 ChatGPT 로그인 상태를 사용합니다. **ChatGPT 탭이 없거나 모든 탭이 메모리에서 해제되면**, 확장프로그램이 로그인 세션과 사용량을 직접 조회합니다. 조회를 위해 탭이나 숨겨진 창을 자동으로 만들지 않습니다. 팝업을 닫으면 주기적인 조회도 멈춥니다.

탭 없는 조회는 실험 기능입니다. ChatGPT 서버의 접근 제한이나 브라우저 쿠키 설정에 따라 실패할 수 있습니다. 로그인이 만료되거나 직접 연결이 차단되면 **ChatGPT 열기**로 로그인 상태를 확인하고 다시 조회하세요. 이 경우에는 ChatGPT 탭을 열어둔 기존 방식으로도 사용할 수 있습니다. 연결되지 않은 상태에서 예전 수치를 현재 수치처럼 표시하지 않습니다.

열려 있는 ChatGPT 탭이 있으면 기존 방식으로 그 탭의 계정·워크스페이스를 조회합니다. 여러 탭 중에는 현재 보고 있는 탭을 우선하고, 그렇지 않으면 최근 사용한 탭을 선택합니다. 해당 탭의 조회가 실패해도 다른 계정이나 로그인 세션으로 임의 전환하지 않습니다. **탭이 없을 때는 로그인 세션의 계정 또는 서버 기본 계정**을 사용하므로, 특정 워크스페이스의 사용량을 확인하려면 해당 ChatGPT 탭을 열어두세요.

초기화 안내에 마우스를 올리면 정확한 초기화 시각과 마지막 조회 시각을 볼 수 있습니다. 초기화 시간이 지나면 서버에 다시 확인하며, 확인 없이 잔여량을 100%로 바꾸지 않습니다.

## 데이터와 권한

전체 내용은 [개인정보처리방침](PRIVACY.md)에서 확인할 수 있습니다.

필요한 사이트 권한은 `https://chatgpt.com/*` 하나입니다. 쿠키, 방문 기록, 전체 사이트, 디버거 권한은 요청하지 않습니다.

탭을 사용하는 경로는 ChatGPT 페이지가 평소 보내는 요청의 인증 헤더를 그 페이지의 메모리 안에서만 잠시 사용합니다. 탭 없는 경로는 브라우저가 기존 로그인 쿠키를 ChatGPT의 `/api/auth/session` 요청에 첨부하고, 응답의 인증 토큰을 확장프로그램 서비스 워커 메모리에서 해당 조회 동안만 사용합니다. 쿠키를 직접 읽는 권한이나 저장소 권한을 추가하지 않습니다.

팝업에는 사용 비율·초기화 시각 같은 정규화된 숫자만 전달합니다. 인증 토큰·계정 ID·이메일·대화 내용을 디스크나 확장프로그램 저장소에 기록하지 않고, 인증 응답이나 원문 오류를 로그에 남기지 않습니다. 직접 조회 완료 전 세션을 다시 확인해 로그아웃·계정 변경이 감지되면 이전 결과를 버립니다. 로그인 세션이 계정 식별자를 제공하지 않는 경우에는 토큰 변경도 보수적으로 계정 변경으로 취급합니다. ChatGPT 이외의 서버 전송, 분석 도구, 원격 코드도 없습니다.

사용량 조회 주소는 웹 설정 화면에서 확인한 `https://chatgpt.com/backend-api/wham/usage`입니다. 탭 없는 경로는 `https://chatgpt.com/api/auth/session`도 사용합니다. 두 주소 모두 공개 API 계약이 아닌 웹사이트 내부 경로이며, 세션 응답의 `accessToken`을 사용하는 방식은 실제 Chrome 로그인 환경에서 검증해야 합니다. OpenAI가 내부 방식을 바꾸면 확장프로그램 수정이 필요할 수 있습니다. 이 수치는 설정 화면의 플랜 사용 한도이며, 토큰 개수를 계산하는 기능은 아닙니다.

## 개발 및 검증

런타임 의존성은 없습니다. Node.js 20 이상에서:

```sh
npm test
npm run icons
npm run package
```

패키지는 `dist/how-many-token-1.0.0.zip`에 생성됩니다. 소스, 아이콘, 설명서만 포함하며 테스트·미리보기 코드와 테스트 결과 이미지는 제외합니다.

UI를 샘플 데이터로 확인하려면:

```sh
npm run preview
```

- `http://127.0.0.1:8765/?percent=79`
- `http://127.0.0.1:8765/?percent=0`
- `http://127.0.0.1:8765/?error=NO_TAB`
- `http://127.0.0.1:8765/?error=LOGIN_REQUIRED`
- `http://127.0.0.1:8765/?error=DIRECT_BLOCKED`

이 로컬 미리보기만 샘플 데이터를 사용합니다. 설치한 확장프로그램은 실제 사용량 조회만 수행합니다.

구조:

- `src/page-usage.js`: ChatGPT 페이지 내부의 인증 연결과 사용량 조회
- `src/content.js`: 숫자로 제한한 조회 결과를 전달
- `src/background.js`: ChatGPT 탭 선택과 응답 검증
- `src/session-usage.js`: 탭이 없을 때 로그인 세션으로 직접 조회, 세션 재확인, 숫자로 제한한 응답
- `src/usage.js`: 주간 한도 선택, 잔여량·시간·색상 계산
- `popup.html`, `src/popup.*`: 팝업 화면

자동 테스트는 모의 응답으로 탭 선택, 탭 없는 조회, 로그인 만료, 차단, 계정 전환, 중복 요청 및 민감 정보 제외를 검증합니다. 실제 Chrome 설치 후에는 확장프로그램과 기존 ChatGPT 탭을 새로고침하고 다음을 확인하세요.

- 로그인한 뒤 모든 ChatGPT 탭을 닫아도 새 탭이 생성되지 않고 사용량이 표시되는지
- 설정 화면과 잔여량이 일치하는지, 확장프로그램을 새로고침해도 로그인 세션으로 다시 연결되는지
- 로그아웃 후에는 예전 수치 대신 로그인 안내가 표시되는지
- 직접 조회가 차단될 경우 안내가 표시되고, ChatGPT 탭을 열면 기존 경로로 조회되는지
- 워크스페이스를 바꾼 ChatGPT 탭을 열어두면 그 탭의 수치를 사용하는지
- 라이트·다크 자동 전환
